### 🚀 Featured Projects

#### 🏃 VitaLink — IoT Athlete Health Monitoring Platform
> Real-time health monitoring system for athletes, coaches, and analysts.

- **Frontend**: Next.js 14 (App Router) · TypeScript · Tailwind CSS · Clean Architecture (4 layers)
- **Backend**: Node.js/Express · .NET · SignalR (real-time) · JWT auth · Role-based routing
- **Features**: Live health metrics dashboard · Coach Dashboard · AI health insights · Analyst portal (Streamlit)
- **Deployed on**: Vercel (frontend) + Vercel Serverless (historical data service)
